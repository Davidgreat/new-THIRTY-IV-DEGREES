## Latest: 5.3.3

[Download the installable School OS 5.3.3 update](SchoolOS_5.3.3_Central_Classroom_Update.zip?raw=true)

[Installation and central configuration guide](SchoolOS_5.3.3_README.md) · [Free live-class research](SchoolOS_Free_Live_Class_Research.md)

Platform Super Admin configures one LiveKit-compatible media service for every school, with encrypted secrets, isolated classrooms and optional explicit school overrides. Includes previous class notifications/reminders, persistent read state, notification/save sounds and separated Employment buttons.

A paid LiveKit Cloud subscription is not required. Native full-class mode needs a compatible hosted project or self-hosted media server, separate from ordinary shared cPanel. Provider/server capacity and allowances apply; the direct fallback remains limited to eight participants. Cloudflare is researched but its adapter is not included.

Back up files, database and private keys, end active classes, test on staging, then install via **Platform Super Admin → Updates & Plugins → Core updates**. Configure under **Setup & account → Platform live classrooms**. Click **Enable sound** once for browser audio.

Local validation includes 587 role-page checks, actual central-only teacher-plus-nine-student audio/video, cross-school and demo isolation, UI/sound checks and installer recovery/rollback. Production hosting, network and large-class acceptance remain required.
