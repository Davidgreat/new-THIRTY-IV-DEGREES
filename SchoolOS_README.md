# School OS downloads

## Latest: 5.3.16 — daily pupil bus records and parent–driver chat

[Download the installable update](SchoolOS_5.3.16_Driver_Daily_Transport_Update.zip?raw=true)

[Installation and feature guide](SchoolOS_5.3.16_README.md) · [Validation report](SchoolOS_5.3.16_Validation.md)

The driver’s main dashboard now includes the glass interface, pie/seven-day charts and Today’s pupils. Generic My Tasks is removed from the normal driver menu, and an old Tasks bookmark redirects to the dashboard.

Drivers select a pupil and record Picked up, Not picked up, On home bus or verified Drop off. The first valid action opens the dated journey record when needed and saves the pupil state atomically. These records feed the child’s bus history and school transport records. Open parent/driver transport pages update about every eight seconds; draft fields are preserved.

Chat parent and Chat with driver open the same permitted private conversation. Contact is scoped to active bus assignments and verified parent-child links, and is revoked when that shared relationship ends. Existing typing/emojis/reactions remain available. No unrestricted student or schoolwide parent messaging is added.

[Light dashboard preview](SchoolOS_5.3.16_Driver_Home_Light.png) · [Dark dashboard preview](SchoolOS_5.3.16_Driver_Home_Dark.png)

Install through **Platform Super Admin → Updates & Plugins → Core updates**, confirm **5.3.16**, refresh tabs and open **Driver dashboard**. Check the **School bus workspace · 5.3.16** badge. Back up and reconcile open journeys first. No schema migration or new provider is required.

Validated locally: ten daily bus/privacy scenarios, 12 retained transport scenarios, eight browser/live scenarios, 631 role-page requests and five installer/recovery checks.
