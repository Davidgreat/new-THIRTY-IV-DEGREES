# School OS downloads

## Latest: 5.3.13 — HR attendance and staff profiles

[Download the installable update](SchoolOS_5.3.13_HR_Attendance_Profiles_Update.zip?raw=true)

[Installation and feature guide](SchoolOS_5.3.13_README.md) · [Validation report](SchoolOS_5.3.13_Validation.md)

HR overview now shows attendance totals, a bar chart, date filters and named follow-up lists. Staff profiles bring together attendance, leave, private queries and responses, employment documents/history, allowances, advances and payslips, with a direct staff-chat shortcut. HR can record verified attendance corrections with reasons while retaining original clock times.

Missing clock-ins remain separate from recorded absence. No school calendar is assumed; historical dates use current roster information plus recorded attendance rather than an immutable historical headcount. See the guide for exact scope and retained manual processes.

Install through **Platform Super Admin → Updates & Plugins → Core updates**, confirm **5.3.13**, then refresh dashboard tabs. Existing accounts and records remain. Back up and test first; no schema migration or new provider setup is needed.

Validated: eight attendance/query/privacy scenarios, 11 retained HR scenarios, five browser workflows, 623 role-page visits and five installer/rollback checks.
