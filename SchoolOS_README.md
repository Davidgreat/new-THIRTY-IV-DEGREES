# School OS downloads

## Latest: 5.3.15 — driver workspace

[Download the installable driver update](SchoolOS_5.3.15_Driver_Workspace_Update.zip?raw=true)

[Installation and feature guide](SchoolOS_5.3.15_README.md) · [Driver audit and validation](SchoolOS_5.3.15_Driver_Audit.md)

Dedicated driver home and six clear menus: My day, Routes & pupils, Trip history, Reports, Route updates and Vehicle care. Includes glass surfaces, readable themes, a pupil-outcome donut/pie chart, seven-day journey chart and phone-friendly pupil controls.

Assigned-vehicle reporting works before the first trip. Route updates stay in the driver workspace and reach allocated pupils/linked guardians. Home boarding is separate from verified guardian handover. Completion requires all records and a vehicle-clear confirmation; older unresolved journeys have a coordinator-only evidence-based review path. Existing driver/management/child privacy boundaries remain enforced.

[Light preview](SchoolOS_5.3.15_Driver_Light.png) · [Dark preview](SchoolOS_5.3.15_Driver_Dark.png)

Install through **Platform Super Admin → Updates & Plugins → Core updates**, confirm **5.3.15**, then refresh dashboard tabs. Back up first and finish active journeys before installation or rollback. Existing accounts and assignments remain. No schema migration or external provider is required. Read the guide for the latest-location GPS limit and new passenger-state rollback implications.

Validated locally: 12 integration/privacy scenarios, six browser workflows, 631 role-page visits, PHP/JavaScript syntax and five installer/recovery checks. The production login/page could not be inspected from the empty shared snapshot.
