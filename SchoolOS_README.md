## Latest: 5.3.4 — Learning Studio

[Download the installable School OS 5.3.4 update](SchoolOS_5.3.4_Learning_Studio_Update.zip?raw=true)

[Installation and classroom guide](SchoolOS_5.3.4_README.md) · [Validation summary](SchoolOS_5.3.4_Validation.md) · [Free media-hosting research](SchoolOS_Free_Live_Class_Research.md)

Includes a calm responsive classroom with in-room chat/questions, reactions, raised hands, teacher-managed microphone permissions and formative multiple-choice quick checks. Screen sharing has an explicit Stop sharing button, separate from Pause and End session.

Teachers can pause or reactivate an ended lesson within its scheduled joining window. Permanently closed lessons cannot restart. Finished lessons move into collapsed Past lessons. New lessons use 30-minute duration increments with countdowns.

Retains platform-wide encrypted LiveKit settings, class notifications, save/notification sounds, teacher Employment buttons and prior audit repairs. Student audio requires the configured full-class media service and initial learner/browser consent. Direct fallback remains limited to eight participants with teacher-only audio.

Back up files, database and private keys, end active classes, test on staging, then install through **Platform Super Admin → Updates & Plugins → Core updates**. Saved central media settings remain in place. The isolated public demo needs separate media configuration.

Validated locally: 15 end-to-end Studio checks, seven server contracts, real teacher-plus-nine-student SFU audio/video, six direct-fallback checks, 589 role-page requests, syntax checks and installer recovery/rollback. Production media hosting, real school networks and larger-class capacity still need acceptance tests.
