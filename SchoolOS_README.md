# School OS downloads

## Latest: 5.3.12 — school HR update

[Download the installable HR update](SchoolOS_5.3.12_School_HR_Update.zip?raw=true)

[Installation and field guide](SchoolOS_5.3.12_README.md) · [HR audit and validation](SchoolOS_5.3.12_HR_Audit.md)

A searchable staff register, one-step staff creation, prefilled account links, private appointment/contact/qualification details, induction checklists and clearer school HR workflows. Payroll settings use naira, percentages and editable tax-band rows. Permanent appointments can be open-ended. Named review selectors and school administrator payment controls replace confusing number-only forms.

Install through **Platform Super Admin → Updates & Plugins → Core updates**, confirm **5.3.12**, then refresh dashboard tabs. Existing accounts and historical payroll remain; the update does not invent missing staff details or statutory rates. Back up and test before real payroll. See the guide for manual processes and remaining limits.

Validated: 11 HR server scenarios, browser form/mobile checks, 611 role-page visits and five installer/rollback checks.
