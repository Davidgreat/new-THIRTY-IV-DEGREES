# School OS — latest update

**5.3.22: Librarian workspace**

[Download the installable ZIP](https://github.com/Davidgreat/new-THIRTY-IV-DEGREES/blob/main/SchoolOS_5.3.22_Librarian_Workspace_Update.zip)

A focused librarian dashboard with glass surfaces, actionable counts, a physical-copy donut and request/return trends. Add a title and its copies in one short form, find students/books by name, and lend/renew/return from clear record cards. ISBN checks detect existing school editions. Reservations, overdue reminders/charges, lost/found stock, digital licences and selected QR-label printing stay connected to the existing student, parent and Finance records.

Stock inconsistencies are flagged for explicit review; no old shelf counts are guessed. Parents retain their restricted family book page. Existing records and earlier dashboard/report-card/collector improvements are preserved.

Back up the platform, install through Platform Admin → Core updates and refresh the librarian portal. Current Librarian permission is required; no new tables or paid services are added.
