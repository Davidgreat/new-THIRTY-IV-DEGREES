# School OS downloads

## Latest: 5.3.9 — School Circle chat and mobile experience

[Download the installable School OS 5.3.9 update](SchoolOS_5.3.9_Social_Chat_Update.zip?raw=true)

[Installation and contact-policy guide](SchoolOS_5.3.9_README.md) · [Validation summary](SchoolOS_5.3.9_Validation.md)

Social chat has no topic/subject field. Search permitted names with server-side pagination, select recipient chips, reuse direct conversations and exchange messages in a responsive chat view.

Student direct contacts are classmates, their linked parents/guardians and assigned teachers. School colleagues can chat with each other. Student-to-owner and student-to-non-teaching-staff private chat is denied in both directions. Every member pair is checked for groups, including older conversations, with batched group checks. Read the policy table in the guide.

Assigned drivers/transport managers can send one-way route notices to allocated learners and guardians. Librarians can send fixed return reminders for issued loans. These do not grant private student-chat access.

Notifications start compact with an unread count and Show/Hide details. Sound defaults on after a browser interaction, with brief unread reminders while the page is visible. Sound and Pause rotation buttons are removed; reduced-motion preferences and browser mute/autoplay controls remain applicable.

The phone homepage uses swipeable highlights, optional discovery content, shorter previews and a demo/start dock. The website Pause motion button is removed, and preview images reflect the new notification design.

Retains earlier classroom/media, waiting-room, mobile-fit, account wording and book-icon changes. Back up files, database and private keys, end active classes, test on staging, then install through **Platform Super Admin → Updates & Plugins → Core updates**. Confirm 5.3.9 and refresh tabs. Existing messages/settings are preserved; conversations outside the new policy become unavailable. No schema change is required.

Validated: eight policy/scope scenarios, nine UI/audio/chat/mobile scenarios, positive batched-group/message checks, 320px layouts, refreshed previews, 591 role-page checks, syntax/package hashes and installer recovery/rollback. Real phone/browser acceptance is still appropriate.
