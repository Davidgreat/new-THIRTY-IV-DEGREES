# School OS downloads

## Latest: 5.3.17 — home travel choices and staff attendance

[Download the installable update](SchoolOS_5.3.17_Transport_Staff_Attendance_Update.zip?raw=true)

[Installation and feature guide](SchoolOS_5.3.17_README.md) · [Validation report](SchoolOS_5.3.17_Validation.md)

Not travelling home now saves while morning pickup is still open. The decision is stored as a labelled home plan instead of wrongly trying to dispatch a second live trip. Actual home boarding activates that same plan after pickup is closed, preserving non-travel choices and all dispatch/guardian checks. Drop off is visible with instructions explaining boarding and approved-collector requirements; no separate drop-off route assignment is needed.

A shared My staff attendance bar now provides Clock in, Clock out and recent history at the top of employee pages. Driver, teacher, HR, warden, librarian, store, communications, Admissions and employed-administrator workflows were exercised. Active staff must be linked to their HR record; missing links/activation are explained. Admissions gains its missing self-attendance access without HR management authority.

[Mobile attendance preview](SchoolOS_5.3.17_Staff_Clock_In.png)

Install through **Platform Super Admin → Updates & Plugins → Core updates**, confirm **5.3.17** and refresh staff/driver/parent tabs. Back up first and coordinate record entry during the update. No schema migration or external provider is required. See the guide before rolling back planned home records.

Validated locally: nine server scenarios, eight browser/role/refresh scenarios, 643 role-page visits and five installer/recovery scenarios.
