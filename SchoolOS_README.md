# School OS downloads

## Latest: 5.3.10 — typing, emojis and message reactions

[Download the installable School OS 5.3.10 update](SchoolOS_5.3.10_Chat_Typing_Reactions_Update.zip?raw=true)

[Installation and feature guide](SchoolOS_5.3.10_README.md) · [Validation summary](SchoolOS_5.3.10_Validation.md)

Open School Circle conversations now show who is typing, including multiple group participants. Draft text is never sent; stopped/abandoned signals expire. Visible chats update approximately every two seconds.

A smile button inserts emoji into messages. Message-level React controls offer quick choices and a custom single-emoji option. Reactions aggregate by count, persist after reload and allow each person to replace/remove their own selection. Flags, skin tones, keycaps and joined family sequences are supported.

Existing school/contact/group permissions are rechecked for typing, reaction changes and snapshots. No new private contact or student messaging permission is created.

Retains searchable topic-free chat, scoped service notices, compact notifications, mobile website improvements and all previous classroom/waiting-room/account/book-icon repairs.

Back up files, database and private keys, end active classes, test on staging, then install through **Platform Super Admin → Updates & Plugins → Core updates**. Confirm 5.3.10 and refresh chat tabs. Existing accounts, conversations and saved media settings remain in place; no schema migration or external service is required.

Validated: six server/privacy/Unicode scenarios, nine two-account browser scenarios, group presence, six phone/landscape menu checks, 593 role-page requests, syntax/package hashes and installer recovery/rollback. Actual school browser/network acceptance remains appropriate.
